# Projeto de Ciência de Dados Aplicada à Nutrição

## Objetivo
Análise de dados nutricionais utilizando técnicas de Data Science e Machine Learning para prever a perda de peso de pacientes.

## Dataset
O projeto utiliza quatro datasets:
- patients.csv
- diets.csv
- nutritionists.csv
- outcomes.csv

## Técnicas Utilizadas
- Integração e limpeza de dados
- Análise exploratória
- Clustering com K-Means
- Modelos preditivos
- Random Forest
- Linear Regression

## Estrutura do Projeto
- data/: datasets
- notebook/: notebook principal
- relatorio/: relatório final
- presentation/: apresentação final

## Bibliotecas
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn
